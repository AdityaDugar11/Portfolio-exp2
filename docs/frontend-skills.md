# Frontend skills behind the portfolio

Research snapshot from 25 November 2026. A web search identified Skills.sh and the original skill repositories. A Scrapling crawl followed every skill listing in three curated topics, removed duplicates, and checked the resulting 26 pages. Two listings led to unavailable entries. The all-time leaderboard supplied adoption figures, and the publishers' instructions guided the final selection. [Design & UI](https://www.skills.sh/topic/design) · [Frontend & React](https://www.skills.sh/topic/react) · [Next.js](https://www.skills.sh/topic/nextjs) · [Leaderboard](https://www.skills.sh/)

## Decisions for this portfolio

| Source | Decision |
| --- | --- |
| [Anthropic Frontend Design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) | Aditya's diary sets the visual hierarchy. His name and introduction open the page. Charcoal lettering carries the text, white space makes the entries easy to scan, and lime gives selected words and actions the feel of a highlighter mark. |
| [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md) | Section navigation should work with a keyboard and preserve a visible focus indicator. Visitors who request reduced motion should be able to read each entry immediately. |
| [Emil Kowalski's animation standards](https://github.com/emilkowalski/skills/blob/main/skills/review-animations/STANDARDS.md) | Opening the diary earns a longer entrance. Repeated actions deserve a quicker response. Use a short ease-out on interactive elements and let the visitor interrupt navigation. |
| [Impeccable](https://www.skills.sh/pbakaus/impeccable/impeccable) | Judge the handwriting and paper details at the sizes visitors will actually read them. Review both phone and desktop layouts for legibility, alignment, and spacing. |
| [Vercel React Best Practices](https://github.com/vercel-labs/agent-skills/blob/main/skills/react-best-practices/SKILL.md) | Its guidance on initial JavaScript cost informed the stack decision. Astro generates the portfolio as static HTML, and native browser JavaScript handles the interactions. |
